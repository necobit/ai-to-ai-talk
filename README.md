# AI-to-AI Talk

LMStudioを使用してAI同士が自律的に会話するシステムです。2つのAIエージェントがtmuxの分割画面でリアルタイムに会話を行います。

## クイックスタート

### 前提条件

- Python 3.10以上
- [LMStudio](https://lmstudio.ai/)がインストール済み
- tmux

### 1. LMStudioを起動

LMStudioを起動し、ローカルサーバーを開始してください（デフォルト: `http://127.0.0.1:1234`）

### 2. 実行

```bash
./start_tmux.sh
```

初回実行時は自動的に仮想環境の作成と依存パッケージのインストールが行われます。

### 3. モデル選択

起動時にLMStudioで利用可能なモデル一覧が表示されます。使用するモデルを番号で選択してください。

### 4. 会話開始

選択後、tmuxの左右分割画面でAI同士の会話が自動的に始まります。

- **終了**: `Ctrl+C` または tmuxセッションを閉じる (`Ctrl+B` → `D` でデタッチ)

## 詳細解説

### システム構成

```
ai-to-ai-talk/
├── start_tmux.sh      # メイン起動スクリプト
├── setup.py           # モデル選択
├── conversation.py    # 会話メインロジック
├── agents.py          # AIエージェントクラス
├── config.py          # 設定・プロンプト生成
└── requirements.txt   # 依存パッケージ
```

### 動作の仕組み

1. **セッション生成**: Agent AがLLMを使ってランダムな会話設定を生成
   - 関係性（友人、先輩後輩、店員と客など）
   - 話題（趣味、仕事、日常など）
   - 2人のキャラクター（名前、年齢、話し方など）

2. **会話の進行**: 2つのエージェントがファイルベースのメッセージングで交互に発言
   - `/tmp/ai_conversation_message.txt`: メッセージ本文
   - `/tmp/ai_conversation_turn.txt`: 発言順管理

3. **会話の終了**: 別れの挨拶を検知すると自動的にセッション終了
   - 例: 「またね」「じゃあね」「お疲れ様」など

4. **連続セッション**: 1つの会話が終わると、新しい設定で次の会話が自動開始

### ファイル詳細

#### `config.py`

- API設定（LMStudioエンドポイント）
- 会話設定（最大ターン数など）
- システムプロンプト生成ロジック
- 別れの挨拶キーワード

#### `agents.py`

- `Agent`クラス: OpenAI互換APIを使用するエージェント
- 会話履歴の管理
- `<think>`タグの除去（推論モデル対応）

#### `conversation.py`

- メインの会話ループ
- ランダムセッション生成
- タイピングアニメーション表示
- シグナルハンドリング（Ctrl+C対応）

### カスタマイズ

#### 会話ターン数の変更

`config.py`の`MAX_TURNS`を変更:

```python
MAX_TURNS = 20  # デフォルト: 20ターン
```

#### LMStudio以外のAPIを使用

`config.py`のAPI設定を変更:

```python
API_BASE_URL = "http://127.0.0.1:1234/v1"  # エンドポイント
API_KEY = "lm-studio"                       # APIキー
```

### トラブルシューティング

#### LMStudioに接続できない

- LMStudioが起動しているか確認
- ローカルサーバーが開始されているか確認（LMStudioの「Local Server」タブ）
- ポート番号が1234か確認

#### 会話が始まらない

- モデルがロードされているか確認
- ターミナルのエラーメッセージを確認

#### tmuxセッションが残っている

```bash
tmux kill-session -t ai-talk
```
